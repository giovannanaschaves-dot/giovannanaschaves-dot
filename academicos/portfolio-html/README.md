# Página Pessoal de Portfólio (HTML e CSS)

Projeto desenvolvido em HTML e CSS com o objetivo de criar uma página pessoal de portfólio, aplicando conceitos de estruturação de páginas web, organização de conteúdo e estilização visual.

## 🚀 Tecnologias

* HTML  
* CSS  

## 📚 O que aprendi

* Estruturação de páginas com HTML semântico  
* Organização de conteúdo em seções (header, section, footer)  
* Criação de menus de navegação com links internos  
* Inserção de imagens e links externos  
* Estilização de páginas utilizando CSS  
* Uso de cores e identidade visual (rosa bebê e marrom)  
* Aplicação de layout com Flexbox e Grid  
* Criação de formulários simples em HTML  
* Organização de portfólio com projetos reais  
* Separação entre estrutura (HTML) e estilo (CSS)  

## ▶️ Como executar

1. Baixe ou clone o repositório  
2. Abra o arquivo `index.html` no navegador  

## 📌 Observações

Este projeto foi desenvolvido como atividade acadêmica com o objetivo de praticar a criação de páginas web utilizando HTML e CSS. A página apresenta informações pessoais, habilidades, linguagens utilizadas, projetos desenvolvidos e um formulário de contato, com foco em organização visual e boas práticas de desenvolvimento.
